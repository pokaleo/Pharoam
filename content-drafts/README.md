# Content drafts

Content drafted with AI and **not yet reviewed**. Nothing here is built into the content pack or shipped with the app: `pnpm content:build` reads only `data/` and `content/`.

Each skill's question-bank items arrive here in their own pull request, in `items/<skill>/`. The founder reviews them in that PR (PRD I3, MVP S20.1). Once approved, the items move into [`content/items/<skill>/`](../content), each gaining `review: { by: The Pharoam founder, at: <date> }`, and are deleted from here. An item never ships without its review recorded.
