# Neutral theme

The theme and artwork the app uses when `brand/` is absent: plain greys, the system's fonts and a plain circle in place of the wordmark and icon. It provides every file `brand/` does (`src/build/brand.ts`), so forks build and run without the Pharoam brand ([LICENSING.md](../../../../../LICENSING.md), [TRADEMARKS.md](../../../../../TRADEMARKS.md)). AGPL-3.0-only, like the rest of the code.
